# E04 下一拍插值/外推方法

本文说明 E04 中 `pva_pred_backward_o1_kp1` 和
`pva_pred_backward_o2_kp1` 的数学依据、离散公式、误差阶和实现边界。

严格地说，这两种方法是在历史采样区间之外计算 `k+1` 状态，因此属于
**外推（extrapolation）**，而不是区间内部的插值。它们不使用 Ruckig
动力学模型，也不读取参考轨迹的 V/A 真值；唯一的导数信息来源是截至 cycle
`k` 已经可用的位置测量。

## 1. 记号与前提

设：

- `x_k = x(t_k)` 是 cycle `k` 的位置测量；
- 采样周期固定为 `h`，E04 中 `h = 0.01 s`；
- `t_{k+1} = t_k + h`；
- 轨迹在所用历史窗口内足够光滑；
- 预测范围恰好为一个采样周期。

两种方法都属于单边、严格因果的有限差分外推，只使用
`x_k, x_{k-1}, ...`，不读取 `x_{k+1}`。

## 2. 系数的数学来源

这些系数统一由 Taylor 矩匹配得到：将历史位置在 `t_{k+1}` 附近展开，
通过矩条件消去不需要的低阶项。位置外推以及 O2 的导数权重，也可以等价地
理解为对最近的位置样本构造 Newton/Lagrange 多项式，并在 `t_{k+1}` 求值
或求导。O1 的 V/A 则是先外推 `x_hat_{k+1}`，再应用一阶端点后向差分。

对于目标导数阶数 `m`，令历史样本相对 `t_{k+1}` 的无量纲偏移为

```text
r_j = -(j + 1),  j = 0, 1, ...
```

并构造

```text
x^(m)(t_{k+1}) ≈ (1 / h^m) Σ c_j x_{k-j}.
```

将每个 `x_{k-j}` 在 `t_{k+1}` 处作 Taylor 展开后，选择系数 `c_j` 使

```text
Σ c_j r_j^q = 0    (q ≠ m)
Σ c_j r_j^m = m!
```

在所要求的多项式次数内成立，就得到代码中使用的单边外推权重。能额外消去
多少个 Taylor 项，决定了 O1 或 O2 的截断误差阶。

## 3. `pred_backward_o1_kp1`

### 3.1 位置外推

O1 使用最近三个位置，并假设下一拍的二阶离散差分与当前相同：

```text
Δ²x_{k+1} = Δ²x_k.
```

由此得到

```text
x_hat_{k+1} = 3 x_k - 3 x_{k-1} + x_{k-2}.
```

这也等价于用 `x_{k-2}, x_{k-1}, x_k` 构造二次插值多项式，再向前外推
一个采样周期。

### 3.2 速度和加速度

将外推的 `x_hat_{k+1}` 放入一阶端点后向差分：

```text
v_hat_{k+1}
    = (x_hat_{k+1} - x_k) / h
    = (2 x_k - 3 x_{k-1} + x_{k-2}) / h

a_hat_{k+1}
    = (x_hat_{k+1} - 2 x_k + x_{k-1}) / h²
    = (x_k - 2 x_{k-1} + x_{k-2}) / h².
```

三者都表示 `t_{k+1}`。其截断误差为：

| 分量 | 截断误差 |
|---|---:|
| `P` | `O(h³)` |
| `V` | `O(h)` |
| `A` | `O(h)` |

方法整体由精度最低的 V/A 决定，因此命名为 O1。它需要三个位置样本；历史
不足时进入 startup，V/A 暂时置零。

## 4. `pred_backward_o2_kp1`

O2 通过更高阶的单边多项式/Taylor 矩条件，直接为 `t_{k+1}` 构造二阶
精度的 V/A 权重。

### 4.1 位置

用最近四个位置构造三次多项式，并向前外推一个采样周期：

```text
x_hat_{k+1}
    = 4 x_k - 6 x_{k-1} + 4 x_{k-2} - x_{k-3}.
```

它等价于令下一拍的四阶离散差分为零，即局部轨迹由三次多项式描述。

### 4.2 速度

用最近三个位置构造二次多项式，在 `t_{k+1}` 对该多项式求一阶导数：

```text
v_hat_{k+1}
    = (5 x_k - 8 x_{k-1} + 3 x_{k-2}) / (2 h).
```

### 4.3 加速度

用最近四个位置构造三次多项式，在 `t_{k+1}` 对该多项式求二阶导数：

```text
a_hat_{k+1}
    = (3 x_k - 8 x_{k-1} + 7 x_{k-2} - 2 x_{k-3}) / h².
```

截断误差为：

| 分量 | 截断误差 |
|---|---:|
| `P` | `O(h⁴)` |
| `V` | `O(h²)` |
| `A` | `O(h²)` |

所以整体命名为 O2。它需要四个位置样本；历史不足时进入 startup，V/A
暂时置零。

## 5. 两种外推的差异

| 特征 | O1 | O2 |
|---|---|---|
| 历史位置数 | 3 | 4 |
| 多项式构造 | P 为二次外推；V/A 为一阶端点差分 | P/A 基于三次、V 基于二次 |
| V/A 精度 | `O(h)` | `O(h²)` |
| 启动所需历史 | 较短 | 多一拍 |
| 平滑无噪声轨迹 | 精度较低 | 通常更准确 |
| 位置噪声敏感性 | 相对较低 | 通常更高 |
| 突变或模型失配 | 可能产生外推误差 | 更可能过冲或振荡 |

O2 并不意味着在所有实际测量上都优于 O1。加速度公式需要除以 `h²`，而 O2
的权重绝对值也更大，因此位置噪声、量化误差和采样抖动可能被明显放大。

## 6. E04 中最终送给 Ruckig 的目标

E04 已知计划位置，并声明 `P[k+1]` 可以提前获得。`ScheduledStateTargetBuilder`
会按目标的 represented time 从计划轨迹取位置，覆盖 predictor 内部计算的
位置外推值。因此，对这两个 future predictor，实际 raw target 是

```text
(
    P_scheduled[k+1],
    V_hat[k+1],
    A_hat[k+1],
).
```

所以在 E04 当前实验设计中：

- 内部的 `x_hat_{k+1}` 体现方法的完整数学定义；
- 真正影响方法间比较的主要是 `V_hat[k+1]` 和 `A_hat[k+1]`；
- 五种有限差分方法都不读取参考 V/A；
- future O1/O2 的 target age 为 0；
- endpoint backward O1/O2 estimator 的 target age 为 1；
- delayed centered O2 estimator 的 target age 为 2。

这也是 future predictor 在 E04 的平滑、等间隔、无位置噪声解析轨迹上通常
比过去时刻 estimator 滞后更小的主要原因。
