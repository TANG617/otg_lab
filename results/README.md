# Experiment Results

Each directory contains the four reference-curve plots in PNG and SVG format.

- `full/`: the original full comparison
- `selected-2/`: the original selected-method comparison
- `middle-selected-2/`: the second selected-method comparison
- `estimator/`: the current position-only estimator experiment; this directory
  is regenerated by `run_experiments.py` and also contains the metrics CSV
