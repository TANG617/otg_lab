# Claim--evidence matrix

This file is the human-readable view of `claims.yaml`. Stable Claim IDs must
not be renumbered. “Allowed” means that the evidence can support the exact
canonical wording under the stated boundary; it does not authorize a broader
paraphrase.

## Status vocabulary

| Status | Meaning |
|---|---|
| `confirmed_current` | Supported by current code, controlled current artifacts, or a formal derivation under stated assumptions |
| `confirmed_frozen_scope` | Supported only within the immutable frozen protocol scope |
| `negative_current` | A current controlled observation that rejects or fails to support the tested proposition |
| `exploratory_confounded` | Numeric observation retained, but the intended comparison identity or inference is confounded |
| `nonconfirmatory_frozen` | A fresh locked result whose raw data and statistical estimate are retained, but one or more preregistered validity gates failed. Descriptive effects may be reported with the failure disclosed; confirmatory verbs and causal performance claims are prohibited. |
| `not_evaluated` | Evidence needed for the proposition has not been collected under a suitable design |
| `external_blocker` | Requires hardware, licensed access, independent data, or another unavailable external condition |

## Section gates

- **Title:** no empirical superiority claim and no E01 or V4 exact-effect value.
- **Abstract:** only claims marked “yes”; C06/C07/N01/N02/N03 must retain their
  limitation or negative wording. E01 and exact V4 percentages are forbidden;
  C15/E02 require qualitative observed, failed-gate, and withheld-confirmation
  wording.
- **Contributions:** C01, C02, C03/C04 as one controlled-study contribution,
  C09, and C10--C12 as scoped execution/identity contributions. C13 is a
  reproducibility practice/result, not an algorithmic contribution. C14 may
  support an evidence-governance contribution, but C15/E02 cannot support a
  superiority headline. E01 is forbidden.
- **Results:** each empirical paragraph follows question → result →
  interpretation → boundary and cites an evidence source.
- **Discussion:** E01 may appear once as an evidence-correction case, never as
  a performance headline. C15/E02 may appear only as an observed
  non-confirmatory result with the frozen gate failure disclosed.
- **Conclusion:** only the marked claims, preserving scope words such as “three
  analytic references,” “single development CSV,” “frozen synthetic v3,” and
  “V4 did not establish a confirmatory benefit.” No exact V4 percentage.

## Quantitative-writing rules

1. Manuscript numbers come from generated macros/tables with source selectors;
   this file is not a numeric source.
2. Percentage reductions state the baseline and pair an absolute value with
   the relative value.
3. “Zero” means zero recorded events over an explicit denominator, not zero
   population probability.
4. RMSE, MAE, maximum error, lag, sampled acceleration-difference jerk,
   `new_jerk`, and internal profile jerk are never interchanged.
5. Current, frozen, and post-freeze values are never combined into one
   experiment row.
6. V4 effect estimates are always labelled observed and non-confirmatory, with
   the failed preregistered validity gate in the same paragraph.
7. V3 77.38% and V4 82.41% remain separately attributed with their own
   commits, denominators, classifications, and section permissions.
