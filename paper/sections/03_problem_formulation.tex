\section{Problem formulation}
\label{sec:problem-formulation}

% CLAIM: C01,C02
We consider a sampled command-generation problem in which the externally
available reference is a stream of position samples, whereas the downstream
\StateToStateOTG{} consumes target states and returns a state reached after one
control update.  The compact input--output relation is
\begin{equation}
  \bigl(p_{0:k}^{\mathrm{ref}},\CurrentState{k}\bigr)
  \longmapsto \CommandState{k+1}.
  \label{eq:compact-problem}
\end{equation}
Here \(p_{0:k}^{\mathrm{ref}}\) denotes only samples available at the current
control tick, not a complete offline trajectory.  The two inputs also have
different physical roles: the reference history describes the signal to be
followed, while \(\CurrentState{k}\) is the execution state from which the next
command profile is planned.

\subsection{Clocks and causal information}

Let \(k\in\NonnegativeIntegers\), let \(\DT>0\) be the nominal control period,
and set \(\ControlTime{k}=k\DT\).  Reference sample \(i\) represents the source
time \(\SourceTime{i}\) and first becomes usable at
\(\AvailabilityTime{i}\).  These times need not coincide: transport or
processing can yield
\(\AvailabilityTime{i}>\SourceTime{i}\), but a causal online computation at
\(\ControlTime{k}\) may use the sample only if
\(\AvailabilityTime{i}\leq\ControlTime{k}\).  We therefore define
\begin{equation}
  \InformationSet{k} =
  \left\{
    \bigl(\ReferencePosition{i},\SourceTime{i},\AvailabilityTime{i}\bigr)
    : \AvailabilityTime{i}\leq\ControlTime{k}
  \right\}
  \cup \{\CurrentState{k}\}.
  \label{eq:information-set}
\end{equation}
The state and availability clocks are retained through every layer rather than
being replaced by an array index.

% CLAIM: C02
An estimator produces a posterior
\(\PosteriorState{\ell}{k}\) representing \(t_\ell\leq\ControlTime{k}\).
When axis measurements have different source times, synchronization to
\(\ControlTime{k}\) is an explicit model-based propagation step, not a
timestamp rewrite.  A future-reference generator then produces
\(\FutureReferenceState{k+H}{k}\), which represents
\(\ControlTime{k+H}=\ControlTime{k}+H\DT\) but is computed from information
available at tick \(k\).  If the posterior is delayed, the physical propagation
interval is
\begin{equation}
  T_{\mathrm{prop}}=\ControlTime{k+H}-t_\ell,
  \label{eq:propagation-interval}
\end{equation}
not merely \(H\DT\).  Posterior delay, requested prediction horizon, command
period, and later plant delay are thus separate quantities.

% CLAIM: C01,C02
The future-reference state is an objective, not yet an executable command.
For target-component mode \(m\in\{\mathrm{P},\mathrm{PV},\mathrm{PVA}\}\), let
\(\rho_{k,H}^{m}\) denote
\begin{equation}
  \rho_{k,H}^{\mathrm{P}} =
  \begin{bmatrix}\bar p_{k+H\mid k}&0&0\end{bmatrix}^{\mathsf T},
  \quad
  \rho_{k,H}^{\mathrm{PV}} =
  \begin{bmatrix}\bar p_{k+H\mid k}&\bar v_{k+H\mid k}&0\end{bmatrix}^{\mathsf T},
  \quad
  \rho_{k,H}^{\mathrm{PVA}} =
  \begin{bmatrix}
    \bar p_{k+H\mid k}&\bar v_{k+H\mid k}&\bar a_{k+H\mid k}
  \end{bmatrix}^{\mathsf T}.
  \label{eq:target-component-selection}
\end{equation}
Omitted components are explicitly set to zero.  The objective may represent a
time farther than the next control boundary.  The
\ExecutableTargetGovernor{} instead constructs
\(\ExecutableTargetState{k+1}\) at \(\ControlTime{k+1}\), and the follower
commits \(\CommandState{k+1}\) at that same boundary.  When no governor is
used, the executable-target state is absent; the request is passed directly to
the follower rather than being relabelled as an executable state.

\subsection{Target and output semantics}

% CLAIM: C01
For the ordinary state-to-state update used in the controlled target-state
study, the explicit indexing contract is
\begin{equation}
  \boxed{\mathrm{target}[k]\longrightarrow\mathrm{output}[k+1]}.
  \label{eq:target-output-contract}
\end{equation}
The target supplied during tick \(k\) is an endpoint request.  The returned
state belongs to the end of the next control interval and is passed forward as
the subsequent current state.  A request representing \(t_k\) and an output
representing \(t_{k+1}\) are therefore not time-aligned even if an
implementation displays them under a common loop index.  This contract exposes
a target-time/output-time problem; it does not establish an unavoidable
physical lag for every OTG or robot.

% CLAIM: C02
The command endpoint is not automatically a measurement.  We reserve
\(\MeasuredState{k+1}\) for feedback with its own source and availability
times, and \(\PlantState{k+1}\) for simulator truth when such truth exists.
The replanning state \(\CurrentState{k}\) can be the previous command,
measurement feedback, or an explicitly defined hybrid selection.  Hence
estimation error, prediction error, governor distortion, follower shaping, and
plant tracking error refer to different state pairs and clocks.

\subsection{Causal differentiation}

% CLAIM: C05
Numerical differentiation illustrates why component construction and timing
cannot be collapsed.  On a uniform grid, backward differences give
\begin{equation}
  \hat v_k^{\mathrm{BW}}
    =\frac{p_k-p_{k-1}}{\DT},
  \qquad
  \hat a_k^{\mathrm{BW}}
    =\frac{p_k-2p_{k-1}+p_{k-2}}{\DT^2}.
  \label{eq:backward-differences}
\end{equation}
The velocity estimate is naturally centred between \(t_{k-1}\) and \(t_k\),
whereas the acceleration estimate is centred at \(t_{k-1}\).  Combining both
with \(p_k\) without propagation therefore mixes represented times.

% CLAIM: C05
A centred stencil aligned to \(t_k\),
\begin{equation}
  \hat v_k^{\mathrm{CD}}
    =\frac{p_{k+1}-p_{k-1}}{2\DT},
  \qquad
  \hat a_k^{\mathrm{CD}}
    =\frac{p_{k+1}-2p_k+p_{k-1}}{\DT^2},
  \label{eq:offline-centered}
\end{equation}
requires \(p_{k+1}\) and is noncausal if declared available at \(t_k\).
After \(p_k\) arrives, the same three-sample pattern can causally estimate
the previous state time,
\begin{equation}
  \hat v_{k-1\mid k}^{\mathrm{CD}}
    =\frac{p_k-p_{k-2}}{2\DT},
  \qquad
  \hat a_{k-1\mid k}^{\mathrm{CD}}
    =\frac{p_k-2p_{k-1}+p_{k-2}}{\DT^2}.
  \label{eq:causal-centered}
\end{equation}
It then has one-sample group delay.  Propagating this posterior to \(t_k\)
introduces a stated motion model; it does not remove the estimate's source
provenance or turn future information into causal information.

\subsection{Command model and distinct feasibility predicates}

% CLAIM: C09
For the direct construction, each axis follows a jerk-controlled triple
integrator over one command interval:
\begin{align}
  a_{k+1} &= a_k+\CommandJerk{k}\DT, \label{eq:direct-a}\\
  v_{k+1} &= v_k+a_k\DT+\tfrac12\CommandJerk{k}\DT^2,
    \label{eq:direct-v}\\
  p_{k+1} &= p_k+v_k\DT+\tfrac12a_k\DT^2
    +\tfrac16\CommandJerk{k}\DT^3. \label{eq:direct-p}
\end{align}
Bounds are componentwise and symmetric:
\(\lvert v\rvert\leq\VelocityLimitSymbol\),
\(\lvert a\rvert\leq\AccelerationLimitSymbol\), and
\(\lvert j\rvert\leq\JerkLimitSymbol\).  No position bound, torque model,
collision constraint, or actuator model is included.

Point admissibility means that a finite state satisfies the V/A bounds.
Stopping viability additionally requires the direction-dependent envelope
\begin{equation}
  a>0 \Rightarrow
  v+\frac{a^2}{2\JerkLimitSymbol}\leq\VelocityLimitSymbol,
  \qquad
  a<0 \Rightarrow
  v-\frac{a^2}{2\JerkLimitSymbol}\geq-\VelocityLimitSymbol.
  \label{eq:stopping-envelope}
\end{equation}
This envelope states that acceleration can be removed at bounded jerk without
crossing the approached velocity boundary.  It is not an application-level
emergency-stop certificate.

One-step reachability additionally requires an allowed profile that connects
the stated current and terminal states while satisfying continuous V/A/J
bounds.  For constant jerk this includes
\cref{eq:direct-a,eq:direct-v,eq:direct-p}; for a piecewise profile it requires
segment-by-segment integration.  Next-step existence is a separate discrete
condition: at least one admissible action must remain at the terminal state.
In particular, point admissibility and stopping viability do not by themselves
establish adjacent-state reachability or next-step existence.

% CLAIM: C09,C11
Finally, sampled-sequence consistency is defined on what was executed.  If
\(\pi_k\) is the committed profile, then it must connect
\(\CurrentState{k}\) to \(\CommandState{k+1}\) under the stated dynamics and
continuous limits.  Only under previous-command feedback and accepted direct
execution does this reduce to consistency between adjacent executable-target
states.  The ordinary-\Ruckig{} diagnostic
\(\FreeDuration(x^{\mathrm{start}},x^{\mathrm{end}})\leq\DT\) belongs solely to
the named start/end solve; it is neither a substitute for profile auditing nor
transferable from a requested endpoint to a different fallback command.

% CLAIM: C12
Command identity follows the same executed-state principle.  A native command
is produced and committed by the declared follower without replacement.  A
shielded command is inspected by an explicitly declared shield and may be
replaced, while a fallback command is the recorded replacement produced by its
named controller.  An algorithm-changing replacement cannot retain the
unqualified identity of the native method that was requested.

\subsection{Evaluation clock and truth boundary}

% CLAIM: C01,C02
Position-following error compares the position named by the protocol---command
or simulated-plant position---with \(p^{\mathrm{ref}}\) at the same represented
time.  Best-lag alignment is a diagnostic, not a replacement for this primary
clock.  The terms estimator delay, prediction horizon, command period,
measurement arrival, and plant delay are therefore reported separately.

The \DevelopmentCSV{} supplies a position sequence evaluated on its declared
fixed grid.  It contains no derivative truth: any velocity or acceleration
constructed from it is an estimate or target diagnostic.  Future-reference
prediction is likewise not ground truth.  The superscript ``truth'' is
reserved for registered analytic or synthetic sources, and offline future
access is labelled as an oracle information condition.
