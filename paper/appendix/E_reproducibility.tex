\section{Reproducibility and artifact workflow}
\label{app:reproducibility}

% CLAIM: C13,C14
The canonical manuscript source is the modular \LaTeX{} project under
\texttt{paper/}; Markdown files under \texttt{paper/logic/} specify the locked
reasoning contract but are not a second manuscript.  The build extracts only
registered bounded evidence, regenerates numbers, tables, figures, and
manifests, runs logic/claim/number/citation/local-path checks, verifies the V3
and V4 frozen boundaries, compiles the document, and audits the \LaTeX{} log.
It uses BibTeX and retains \texttt{main.bbl} for source submission.

The artifact keeps five evidence populations distinct: current analytic
Phase~A and development-CSV outputs; immutable synthetic V3 command evidence;
the separate frozen V3 runtime benchmark after warm-up; the fresh but
non-confirmatory frozen V4 attempt; and post-freeze code or compatibility
evidence.  Whole-trajectory, aligned-cycle, transition, safety, and runtime
denominators remain at their original grain and are never pooled.

Rebuilding the paper does not execute an experiment.  It does not rerun or
resume V3, does not rerun or resume the exactly-once V4 locked test, and does
not execute V5.  V4 report generation reads the bounded CSV/JSON artifacts and
their registered hashes.  The later same-information aid is report-only: it
does not generate trajectories, recompute algorithm outputs, remove any failed
cycle, or alter \texttt{invalid\_method\_identity}.

The versioned source target creates
\texttt{arxiv\_stage\_source\_v1.zip} without replacing the earlier v0
package.  It carries the manuscript, Appendix~F, generated V4 tables and
figure, bibliography material, and portable claim/evidence/number/display
provenance.  The packager fixes ZIP timestamps and permissions, records every
member's SHA-256 digest, extracts the completed archive into a fresh temporary
directory, verifies member order and hashes, and compiles there without
repository inputs.  Local environments, absolute paths, caches, and raw
experimental artifacts are excluded.

The instrumented Python runtime measurements remain results rather than build
requirements.  Reproducing the PDF neither asserts that the recorded pipeline
meets a hard real-time deadline nor turns the large observed V4 effect into a
confirmatory performance benefit.
